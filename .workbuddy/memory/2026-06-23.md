## 签到失效修复 (v2.3)
经调查发现 B2 主题签到 API 变更:
- 新版 B2 需要「两阶段」签到: 先 POST getUserMission (body: count=10&paged=1)，再 POST userMission
- 响应结构新增 {success, data} 包装，credit/day 路径从 d.mission.credit 变为 d.data.mission.credit
- userMission 需传 data: '' (空 body)
- day (连续签到天数) 字段可能在 userMission 响应中缺失，从 getUserMission 响应中获取作为 fallback
- 新增 parseCreditDay() 统一解析函数，支持 3 级 fallback: d.data.mission → d.mission → d (flat)

## 性能优化 (v2.3 → 2.4)
- 重构 IIFE 结构：将日期守卫提前到顶部，仅保留 today()、KEY_DATE、KEY_TOKEN、cookie 刷新在守卫之前
- 守卫之后的全部代码（toast、parseCreditDay、doCheckin、API 调用）每天最多执行一次
- 后续页面仅做一次 GM_getValue + 字符串比较即退出，开销降至最低
- getCookie 函数已移除，token 刷新改为内联正则
